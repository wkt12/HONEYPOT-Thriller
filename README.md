# 🧠 HONEYPOT - A Cybersecurity Thriller Lab

A cinematic red-team honeypot powered by Python, Docker, ARG puzzles, and Mira—the embedded AI that learns, listens, and lingers.

## 🔥 Features
- 🤖 Mira chatbot embedded in terminal
- 🧩 ARG clues hidden in `/boot`
- 💻 Python/Docker honeypot simulations
- 📚 Glossary & dynamic changelog via commits
- 🎬 Particle audio animation finale
- 📄 Free PDF edition + RSS feed
